To create a repository in ESKit, use the **`eskit repo create`** command.

## Command Syntax

```bash
eskit repo create <name> --location <path>
```

## Required Parameters

- **`name`** - The name of the repository
- **`--location`** - The path to the folder where the repository will be created

## Optional Parameters

- **`--type`** - Type of repository (default: `fs` for file system)

## Example

```bash
eskit repo create my-repo --location /path/to/backup
```

This creates a file system repository named `my-repo` at the specified location.

## Additional Options

You can also use these common arguments:
- **`--config`** - Specify a custom config file (default: `.eskit/config.json`)
- **`--host`** - Specify which host to operate on
- **`--dry-run`** - Show the request without executing it
- **`-v, --verbose`** - Enable verbose logging
- **`-d, --debug`** - Enable debug logging
- **`-j, --json`** - Output in JSON format

The repository will be registered with your Elasticsearch cluster and can then be used to store snapshots.

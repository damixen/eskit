# ESKit

ESKit is a **lightweight Elasticsearch toolkit** for managing repositories, snapshots, and indexes.

It provides a command-line interface to help you:

- **Manage repositories** - Create, delete, and view snapshot repositories
- **Handle snapshots** - Create, restore, and delete Elasticsearch snapshots
- **Work with indexes** - Create, delete, and monitor indexes
- **Perform reindexing** - Reindex data from source to destination indexes
- **Archive data** - Pull, sync, and push archive data
- **Manage index lifecycle** - View and manage ILM (Index Lifecycle Management) policies
- **Handle tasks** - Check the status of Elasticsearch tasks
- **Manage jobs** - List and view job details
- **Get AI assistance** - Ask questions to AI models for help with Elasticsearch operations

ESKit uses a configuration file (`.eskit/config.json`) to store settings and can operate against multiple Elasticsearch hosts.
